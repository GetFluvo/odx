# odx-core

Domain types, exit codes and IO traits shared by the odx crates.

Part of [odx](https://github.com/getfluvo/odx), the Odoo Developer eXtension.
This crate is one of the building blocks of the `odx` command
([`odx-cli`](https://crates.io/crates/odx-cli)); its API follows what odx needs
and is not stable. To use odx, install the command:

```console
$ uv tool install odx-cli
$ cargo install odx-cli
```

- User documentation: [odx.readthedocs.io](https://odx.readthedocs.io/)
- API documentation: [docs.rs/odx-core](https://docs.rs/odx-core)
- Source and issues: [github.com/getfluvo/odx](https://github.com/getfluvo/odx)
