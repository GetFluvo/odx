# Configuration

odx reads the `[tool.odx]` table of the project's `pyproject.toml`. Only
`odoo_version` is required; every other key has a default. Unknown keys are
errors, so a typo never goes unnoticed. Keys marked *not used yet* are
accepted, so a configuration can name them already, but have no effect.

Durations are written as a number and a unit: `"90s"`, `"15m"`, `"12h"`,
`"7d"`. Paths are relative to the project root.

The settings of the person rather than the project (forge tokens, mirrors,
local clones, the cache location) live in the
[user configuration](user-config.md).

## `[tool.odx]`

| Key | Type | Description |
| --- | --- | --- |
| `odoo_version` | string | Odoo series of the project, e.g. `"17.0"`. |
| `languages` | list of strings | Languages the project is translated into besides English, as Odoo codes (`"es"`, `"nl_BE"`). Default: none (English only). |
| `project_id` | string | Neutral project identifier for the verdict repository. Default: the first twelve hex digits of the SHA-256 of the project's `origin` URL. |
| `jobs` | integer | Maximum concurrent fetches and merge jobs. Default: the number of CPUs. |
| `cache_dir` | path | Cache directory, relative to the project root. Default: the shared cache directory of the user configuration, else `.odx/cache`. |
| `merge_strategy` | `"rebase"` \| `"merge"` | How merges are applied on top of the base. Default: `"rebase"`. |
| `mergiraf` | `"auto"` \| `"always"` \| `"never"` | When to use mergiraf for conflict resolution. Default: `"auto"`. |
| `on_conflict` | `"abort"` \| `"skip"` | Default conflict policy for merges. Default: `"abort"`. |
| `on_head_change` | `"pin"` \| `"follow-if-green"` \| `"follow"` | Default force-push guard-rail policy. Default: `"follow-if-green"`. |
| `lockfile` | path | Lockfile path, relative to the project root. Default: `odx.lock`. |

## `[tool.odx.mirror]`

The private vault repository.

| Key | Type | Description |
| --- | --- | --- |
| `url` | string | Push URL of the vault repository; must be private. |
| `ref_prefix` | string | Prefix of content-addressed refs. Default: `refs/odx`. |
| `ref_style` | `"refs"` \| `"tags"` | Whether locked commits are kept under refs or tags. Default: `"refs"`, or `"tags"` when the vault protects tags (GitLab, or created with `auto_create`). |
